# Temple images

Drop image files here. They are served from the site root, e.g.
`public/images/deities-alankaram.jpg` → `https://www.templemahendra.in/images/deities-alankaram.jpg`.

## Required

| File | Used by | Notes |
|---|---|---|
| `deities-alankaram.jpg` | About page (sanctum photograph) | The colour photo of the three deities in floral alankaram — Sri Lingammal (left, green saree), Sri Renukadevi (centre), Sri Chinnammal (right, red saree). Landscape or portrait both work; ≥1200px wide recommended, JPEG quality ~80. |
| `temple-hero.jpg` | Home page hero background | Can be the same photograph. A wide (landscape) crop looks best because it sits behind the hero text. |

Until the files are added, the About page hides its photograph automatically and the
Home hero falls back to its maroon gradient — nothing breaks.
